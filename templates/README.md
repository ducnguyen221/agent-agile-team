# templates/

KHUNG — viết ở `TK3.5`:

- `sprint/` — `SPEC.md`, `PLAN.md`, `PROGRESS.md`, `REPORT.md`, `SPRINT.md` (bốn phần gộp, cho việc rất nhỏ).
- `registry/` — `REQUESTS.md`, `SPECS.md`, `SPRINTS.md`, `feature-spec.md`.
- `project/` — `agile.json`, cấu hình dự án mặc định.

Frontmatter mẫu chỉ dùng tập con YAML mà `scripts/_common.py` đọc được.
