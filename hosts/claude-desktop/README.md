sprint vào dự án. Tab chat của Claude Desktop không nạp skill hay luật từ repo, không chạy được `init`,
`check`, `index`, và không ghi được thư mục dự án — nên không chạy được quy trình sáu bước.

Dùng tab **Code** trong chính ứng dụng Claude (là Claude Code — xem [claude/README.md](../claude/README.md)),
hoặc [Codex](../codex/README.md), [Antigravity](../antigravity/README.md).
